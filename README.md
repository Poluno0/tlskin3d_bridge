# TL Skin Cape ↔ Skin Layers 3D Bridge (Forge 1.20.1)

Клиентский мод. Без него Skin Layers 3D не может строить 3D-слои для скинов, которые загружает TL Skin Cape:
TL хранит скин в своём классе `LightTexture` и сразу закрывает картинку, а Skin Layers умеет читать пиксели только
у обычных скачанных (`HttpTexture`) и динамических (`DynamicTexture`) текстур. В логе это выглядит так:
`Unable to handle skin minecraft:dynamic/skin_0 ... (org.tlauncher.renderer.texture.LightTexture)`.

Мост копирует пиксели скина в момент загрузки в TL и отдаёт их Skin Layers через его собственный интерфейс.
Ничего не отправляется по сети, серверная часть не нужна.

Проверено только разбором кода: TL Skin Cape 1.32 и Skin Layers 3D 1.11.4 (Forge 1.20.1). В игре не запускалось.

## Установка

Положите jar в `mods` каждому игроку, у которого стоят **оба**: TL Skin Cape и Skin Layers 3D
(и у TL-игроков, и у игроков с официальным лаунчером). У кого моста нет, тот просто не увидит 3D-слои, всё остальное работает.

## Как собрать jar

1. Создайте пустой репозиторий на GitHub и загрузите в него все файлы этой папки (включая скрытую `.github`;
   если она не загрузилась, создайте файл `.github/workflows/build.yml` вручную и вставьте в него содержимое).
2. Откройте вкладку «Действия», дождитесь зелёной галочки у сборки `build`.
3. Откройте сборку, внизу в разделе Artifacts скачайте `tlskin3dbridge`, распакуйте, внутри будет jar.

Локально: Java 17 и команда `gradlew build`; jar появится в `build/libs`.

## Проверка

1. Запустите игру с TL Skin Cape, Skin Layers 3D и мостом, зайдите в мир (или на сервер).
2. В `logs/latest.log` должна появиться строка `Captured a 64x64 skin image from ...`, а предупреждения
   `Unable to handle skin ... LightTexture` быть не должно.
3. Нажмите F5 (вид от третьего лица) и посмотрите на слои одежды: они должны быть объёмными
   (в настройках Skin Layers 3D должно быть включено отображение слоёв).

## Ограничения

- Skin Layers 3D работает только со скинами 64x64 (HD-скины он не поддерживает сам). Старые 64x32 мост достраивает до 64x64.
- Мост зависит от внутренностей TL Skin Cape и Skin Layers 3D, поэтому после обновления любого из них может перестать работать.
